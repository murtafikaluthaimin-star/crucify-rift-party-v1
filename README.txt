CARA MEMBUAT GIF
==================================================

Pastikan Python sudah terinstall.

Buka terminal VSCode.

Jalankan:

pip install pillow

Kemudian:

python buat_gif.py


Setelah selesai akan muncul:

assets/showreel.gif


==================================================
CARA MENJALANKAN WEBSITE
==================================================

Cara 1:

Buka:

index.html

langsung menggunakan browser.


Cara 2:

Gunakan VSCode + Live Server.

Buka folder:

CRUCIFY-RIFT-PARTY

Kemudian klik kanan:

index.html

Pilih:

Open with Live Server


==================================================
MENGGANTI LINK SOCIAL MEDIA
==================================================

Buka:

index.html


Cari:

href="#"


Kemudian ganti dengan link asli.


Contoh Discord:

href="LINK_DISCORD_KAMU"


Contoh Facebook:

href="LINK_FACEBOOK_KAMU"


Contoh WhatsApp:

href="LINK_WHATSAPP_KAMU"


Contoh Instagram:

href="LINK_INSTAGRAM_KAMU"
